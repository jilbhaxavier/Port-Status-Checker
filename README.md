
# Port Status Checker

## Project Description
Port Status Checker is a Python-based project
that checks whether a specific port on a
given host is open or closed.

## Features
- Accepts hostname or IP address.
- Accepts port number from the user.
- Checks port availability.
- Displays OPEN or CLOSED status.
- Handles invalid inputs.

## Technologies Used
- Python
- Socket Programming

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

python port_checker.py
